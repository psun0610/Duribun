# 디자인 규칙 (필수)

**이 프로젝트의 모든 UI는 `docs/design-system.md` v2.1을 따릅니다.** 화면·스타일·사용자 문구를
만들거나 고치기 전에 그 문서를 먼저 읽으세요. 값이 필요할 때마다 새로 정하지 말고 문서에서 가져옵니다.

시각 기준 캔버스: https://claude.ai/code/artifact/6c3bf9c6-e8a2-4a2a-8c61-5b0b6045cc95
(전체 화면 16개 + 디자인 시스템 시트)

## 색을 새로 만들지 마세요

토큰은 열 개뿐입니다: `#FF6B9D` `#E8437E` `#FFC75F` `#1A1A1A` `#737373` `#A3A3A3` `#F5F5F5`
`rgba(0,0,0,0.08)` `#FFEEF4` `#FFF6E3`.

- 컴포넌트 `.module.scss`에 hex를 직접 쓰지 않습니다. `src/styles/variables.scss`를 거칩니다.
- 새 색이 필요하면 먼저 `docs/design-system.md`와 토큰에 추가하고, 왜 필요한지 남기세요.
- 그라디언트는 한 개뿐이고 **장소 담기 FAB와 코드 카드에만** 씁니다.

## 고정된 값

- 모서리: 사진·패널·리스트 24px / 입력·썸네일 20px / 버튼·pill 999px
- 그림자: 카드 `0 8px 24px rgba(0,0,0,0.08)`, 브랜드 `0 10px 22px rgba(255,107,157,0.34)`
- 글꼴 굵기: 400 / 500 / 700 / 800만. Noto Sans KR에 없는 650 같은 값 금지
- 하단 탭: 홈 · 친구 · (담기 FAB) · 둘러보기 · 설정
- 사진 카드 정보는 이름 / 상태 / 평점·공개여부 **세 줄 고정**

## 문구는 사람 말로 씁니다

`docs/design-system.md`의 "문구 원칙"이 정본입니다. 핵심만:

- **"우리 장소"라는 표현은 쓰지 않습니다.** 화면 제목은 "우리가 다녀온 곳", 탭은 "홈".
- `-어요` / `-예요`체. `-습니다`, 명사형 기능 이름, 슬래시 나열, 괄호 설명 모두 쓰지 않습니다.
- 개발 용어를 그대로 노출하지 않습니다. 탐색 → 둘러보기, 공개/비공개 → 밖에도 보여요/우리끼리만.
- 사용자 문구는 컴포넌트의 `const/`에 COPY 상수로 모읍니다. JSX에 문자열을 흩뿌리지 않습니다.
- **연결 끊기처럼 무거운 화면에서는 발랄한 말투를 쓰지 않습니다.** 담담하고 정확하게 쓰고,
  브랜드 그라디언트 대신 회색 면을 씁니다. "잠시 닫아뒀어요" 같은 표현은 상황을 가볍게 만듭니다.

## 리뷰 상태

문구는 `src/features/review/const/reviewStatus.const.ts` **한 곳에만** 정의합니다.
값 이름이 헷갈리니 주의하세요 — `waiting-partner`는 내가 이미 쓴 상태입니다.

| 값 | 뱃지 문구 |
|---|---|
| `none` | 아직 안 썼어요 |
| `waiting-partner` | 상대 기다리는 중 |
| `partner-waiting` | 내 차례예요 |
| `complete` | 둘 다 썼어요 |

## 아직 코드에 반영되지 않았습니다

v2.1은 문서와 캔버스에만 있습니다. 코드는 아직 예전 값과 문구를 쓰고 있어요.
UI를 건드릴 일이 생기면 그 부분부터 v2.1로 옮기고, 전면 적용은 사용자와 상의하세요.
적용 순서는 `variables.scss` → `src/components/ui` → 화면 컴포넌트입니다.
